# Simulado de Viaturas de Bombeiros

## Publicação no GitHub Pages
1. Envie o arquivo `index.html` e a pasta `materiais/` para a raiz do repositório.
2. No GitHub, acesse **Settings → Pages**.
3. Em **Build and deployment**, escolha **Deploy from a branch**, selecione `main` e `/ (root)`, e salve.
4. Aguarde a publicação. Os botões **Materiais de estudo** abrem os arquivos da pasta `materiais/`.

## Incluído
- Quiz de 90 questões com filtros de dificuldade e progresso salvo no navegador.
- Materiais de aula, diretriz, QFROTAS, anotações pessoais de aula e foto do painel do ABE.

**Importante:** publique o conteúdo completo da pasta do projeto, não apenas o `index.html`, para que os links dos materiais funcionem.
